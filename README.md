# Tablo

Tablo — расширение для Chrome, которое заменяет стандартную страницу новой вкладки персональной панелью закладок. Оно помогает организовать ссылки и быстро обращаться к активности браузера, не покидая страницу.

## Возможности

- Организация закладок по пространствам, папкам и группам.
- Создание, редактирование, перемещение и удаление закладок и папок с помощью drag-and-drop.
- Поиск по закладкам и множественный выбор для массовых действий.
- Просмотр открытых вкладок и недавней истории браузера в боковой панели.
- Переключение между светлой, тёмной и автоматической темами.
- Импорт и экспорт резервных копий всей панели или отдельного пространства в формате JSON.
- Хранение данных приложения локально в Chrome Storage.
- Отмена последнего изменения панели.

## Браузерное демо

Демо использует тот же интерфейс с примерами пространств, папок, закладок, вкладок и истории. Оно открывается без установки расширения, хранит изменения в `localStorage` и позволяет вернуть исходные данные кнопкой сброса.

После публикации через GitHub Actions демо доступно по адресу [rmfomin.github.io/tablo](https://rmfomin.github.io/tablo/). Для локальной сборки выполните `npm run build:demo`; готовая отдельная версия появится в `demo-dist` и не изменяет сборку расширения в `dist`. Pull request получает сборку демо как Actions artifact.

Перед первым деплоем в настройках репозитория откройте **Settings → Pages** и установите **Source → GitHub Actions**. Workflow не включает Pages самостоятельно: GitHub не разрешает `GITHUB_TOKEN` создавать Pages-сайт.

## Требования

- Google Chrome или другой браузер на базе Chromium.
- Node.js и npm.

## Локальная установка и запуск

1. Установите зависимости:

   ```bash
   npm ci
   ```

2. Запустите сборку для разработки в режиме отслеживания изменений:

   ```bash
   npm run watch
   ```

3. Откройте в Chrome `chrome://extensions`.
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение** и выберите каталог `dist` проекта.

Webpack обновляет `dist` после изменения исходного кода. Чтобы применить обновление в Chrome, нажмите кнопку перезагрузки расширения на странице `chrome://extensions`.

## Сборка для продакшена

Создайте оптимизированную сборку:

```bash
npm run build
```

После завершения команды выберите каталог `dist` через **Загрузить распакованное расширение** на `chrome://extensions`.

### Скачать архив из GitHub

Стабильная сборка доступна в [последнем GitHub Release](https://github.com/rmfomin/tablo/releases/latest). Скачайте [архив расширения](https://github.com/rmfomin/tablo/releases/latest/download/tablo-chrome-extension.zip), распакуйте его и выберите распакованный каталог через **Загрузить распакованное расширение** на `chrome://extensions`.

Для публикации новой версии создайте и отправьте тег `v<версия>` после обновления версии расширения, например `v1.0`. GitHub Actions соберёт normal-версию и приложит ZIP к релизу. Для локальной сборки ZIP выполните `npm run build:archive`; архив появится в `builds/tablo-chrome-extension.zip`.

## Доступные команды

| Команда | Описание |
| --- | --- |
| `npm run watch` | Собирает расширение в режиме разработки и пересобирает его при изменении файлов. Расширение заменяет страницу новой вкладки. |
| `npm run watch2` | Собирает расширение в режиме разработки, не заменяя страницу новой вкладки. |
| `npm run build` | Создаёт оптимизированную normal production-сборку в `dist`. |
| `npm run build:archive` | Собирает normal-версию и создаёт ZIP для установки в Chrome. |
| `npm run build:demo` | Собирает отдельную браузерную демо-версию в `demo-dist`. |
| `npm run build:overrideless` | Создаёт production-сборку без замены страницы новой вкладки. |
| `npm run typecheck` | Запускает проверку типов TypeScript без создания файлов сборки. |
| `npm test` | Запускает тесты. |
| `npm run test:watch` | Запускает Vitest в режиме наблюдения. |
| `npm run check` | Последовательно запускает typecheck, тесты и normal-сборку. |
| `npm run clean` | Удаляет каталог сборки `dist`. |

# Улучшения повседневной работы в Tablo — план реализации

> **Для исполнителя:** выполнять этапы последовательно в текущей сессии, сверяясь с дизайн-документом.

**Цель:** добавить попап часто используемых страниц с рекомендациями из истории, переход из поиска к закладке на панели, надёжное обновление фавиконов и настраиваемое напоминание о резервной копии.

**Архитектура:** встроить UI и состояние в существующие React/Zustand компоненты и локальное Chrome Storage. История и существующие команды импорта/экспорта остаются источником данных; не добавлять backend или зависимости.

**Технологии:** React 18, TypeScript, Zustand, Chrome Extensions Manifest V3, SCSS.

**Спецификация:** [2026-10-24-tablo-workflow-features-design.md](../specs/2026-10-24-tablo-workflow-features-design.md)

## Общие ограничения

- Расширение остаётся совместимым с текущими manifest-вариантами Chromium.
- Новые внешние зависимости не добавлять.
- Не менять постоянный URL фавикона ради cache busting.
- Новые настройки хранить в `chrome.storage.local` через существующий storage adapter.
- Не добавлять и не запускать тесты, lint, build или typecheck без отдельной просьбы пользователя.
- Не создавать коммит и не добавлять файлы в staging area.

## Фокус проверки

- Пустая история и пустые рекомендации — попап остаётся рабочим и показывает пустое состояние.
- URL с разными query/hash должны сопоставляться только по согласованной нормализации, не объединяя разные документы ошибочно.
- Удалённая либо свёрнутая папка/группа не должна мешать переходу из поиска и раскрытию найденной закладки.
- Ошибки или пустые результаты Favicon API не должны затирать отображаемую рабочую иконку.
- Старое Chrome Storage без новых полей должно гидратироваться с выключенным напоминанием и значениями по умолчанию.

- Создать `src/newtab/03-widgets/ui/PopularPagesModal/PopularPagesModal.tsx` и `PopularPagesModal.module.scss`: частые URL, исключение уже сохранённых, быстрое открытие и форма добавления.

## Этап 1: обновление фавиконов

- Добавить `favicon` permission в оба manifest-варианта.
- Реализовать получение URL через `chrome.runtime.getURL("/_favicon/")`, с `pageUrl` и размером 32.
- Заменить перезагрузку, которая только выбирает URL из кэша, на повторное получение favicon URL из Chrome API для всех закладок текущего пространства.
- Не сохранять новый URL, если API не вернул пригодный favicon; показать итоговое уведомление.

## Этап 2: попап частых страниц

- Получать историю за последние 7 дней, считать визиты через `chrome.history.getVisits` с ограничением параллельных запросов и показывать до 20 страниц, ранжируя по числу визитов и времени последнего посещения.
- Сопоставлять страницу с Tablo по нормализованному URL без завершающего слеша; сохранить query и path.
- Показывать только страницы, отсутствующие в Tablo. Для каждой указывать число визитов за 7 дней и дату со временем последнего визита; скрывать страницу сразу после добавления.
- Для добавления дать выбрать пространство и папку, создать закладку с URL, названием и favicon из истории, затем показать подтверждение.
- Предусмотреть состояния загрузки, пустой истории и отсутствия несохранённых предложений.

## Этап 3: переход из поиска к закладке

- Расширить `SpaceSearchResult` идентификаторами пространства, папки, группы и закладки.
- Сохранить открытие URL по выбору результата; добавить отдельную кнопку с иконкой `arrow-down-to-dot`, передающую запрос перехода к закладке из `SearchResults` в `NewtabPage`.
- Выбрать пространство, раскрыть свёрнутую папку и содержащую группу, закрыть поиск, прокрутить до `data-id` закладки и временно выделить её через selection store.
- Сохранять текущее поведение открытия результатов истории в новой вкладке.

## Этап 4: напоминание о резервной копии

- Добавить сохраняемые предпочтения: включено/выключено, положительный целочисленный интервал в днях, время последнего полного экспорта, время включения без прежнего экспорта и `snoozedUntil`.
- Для старого storage применить defaults: выключено, интервал 30 дней, даты отсутствуют.
- Подтверждение напоминания открывает системный диалог сохранения через `chrome.downloads.download({ saveAs: true })`; после успешного завершения файла записывать время бэкапа. Отмена и ошибка не сбрасывают таймер; экспорт пространства отметку не меняет.
- Если срок наступил и snooze истёк, показать ненавязчивое окно с действиями экспорта и переноса на завтра; срок проверяется таймером, пока новая вкладка открыта.
- Добавить пункт «Backup reminders» с приложенной иконкой колокольчика и разделителем перед ним. Пункт открывает модальное окно с переключателем напоминаний, input интервала и кнопкой «Check now», которая запускает тот же сценарий напоминания без ожидания срока.

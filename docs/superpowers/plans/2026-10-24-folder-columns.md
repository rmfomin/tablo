# План папок на несколько колонок

Спецификация: `docs/superpowers/specs/2026-10-24-folder-columns-design.md`

## Ограничения

- Сохранить существующие незакоммиченные исправления, не делать git add/commit
- Использовать существующий стек React/TypeScript/Zustand/SCSS, без новых зависимостей
- Билд запускать последовательно после каждой итерации; целевые тесты проверяют запрошенные сценарии раскладки и перетаскивания

## Задачи

- [x] 1. Модель и JSON: `columnSpan`, обновление папки, нормализация и round-trip проверки
- [x] 2. Чистый алгоритм распределения: измеряемые высоты, заголовок первой колонки, продолжения групп, сохранение порядка
- [x] 3. UI: последовательная сетка с span, колонки папки, измерения, продолжения групп, resize с отменой и одним сохранением
- [x] 4. Drag-and-drop: границы колонок, части единой группы, стабильность раскладки, перенос папок, клавиатура
- [x] 5. Целевые тесты, typecheck, билд и отдельное ревью общей реализации

## Проверка интеграции

- Модель предоставляет `columnSpan`, UI использует его без перезаписи при временном ограничении
- Drag читает DOM-границы из спецификации, UI выставляет их для каждой колонки и части группы
- Папка использует одно дерево данных; разбиение влияет только на представление
- Баланс учитывает высоты заголовков; закрытые группы не создают продолжений

## Прогресс

Реализация начата после команды пользователя «делай рекомендуемый вариант»

## Результаты

- `npm run build` выполнен после каждой итерации, финальный normal build успешен
- `npm run typecheck` и `git diff --check` успешны
- 128 функциональных тестов в 19 файлах прошли: раскладка, resize, JSON/storage, доменные операции, старые и новые сценарии перетаскивания, клавиатура
- В браузере на изолированных данных проверены: resize 2→1→2 мышью; сворачивание папки до одной колонки и возврат к двум; перенос закладки между частями группы; перенос всей группы за заголовок продолжения; сворачивание группы через продолжение
- Проверочная страница не запускала persistence и не меняла реальные закладки; её временные файлы удалены, локальный сервер остановлен
- Отдельное ревью выявило два P2: перескок соседних папок из-за display:none при переносе и неправильный выбор соседней папки стрелкой вправо. Оба исправлены с RED→GREEN проверками
- Перенос папки сохраняет место в сетке через visibility:hidden; строки/колонки пересчитываются после завершения жеста
- Открытие всех вкладок через продолжение группы проверено отдельным DOM-тестом: открываются все неархивные закладки исходной группы

## Известные старые падения проверок исходного текста

Отдельно проверены два файла с утверждениями о точном тексте CSS/компонентов: 10 проверок прошли, 7 не прошли. Их условия не выполняются уже в исходном HEAD; существующий дизайн не откатывался ради этих утверждений

- Проверка open-all в том же contract-файле обновлена для обращения ко всей логической группе; её реальное поведение дополнительно покрыто DOM-тестом

# Переключатель раскладки папок

## Замысел

Добавить в меню «Настройки», сразу после «Show group backgrounds», переключатель между свободной раскладкой папок и выравниванием по строкам. По умолчанию оставить текущую свободную раскладку.

## Цели и ограничения

- В режиме выравнивания каждая строка папок занимает высоту самой высокой папки в этой строке; следующая строка начинается ниже неё.
- Сохранить текущий порядок папок, число колонок, адаптивность и поведение drag-and-drop.
- Сохранять выбор как глобальную настройку между запусками и включить её в экспортируемые настройки.
- Не менять содержимое или порядок папок.

## Варианты реализации

- Оставить CSS Grid и переключать алгоритм размещения: свободный режим использует текущие вычисляемые высоты ячеек, режим строк — естественную высоту строк Grid. Выбран этот вариант: он сохраняет существующую разметку и порядок папок.
- Перейти на CSS columns или отдельную раскладку по колонкам: это меняет порядок чтения/перемещения папок и усложняет поддержку текущей логики, поэтому вариант не подходит.

## Решение

Добавить булеву настройку интерфейса со значением по умолчанию `false` и сохранением через существующий механизм настроек. Свитчер разместить сразу после «Show group backgrounds». Включённый режим выравнивает папки рядами по самой высокой папке в каждом ряду; выключенный сохраняет текущую свободную раскладку.

## Не входит в задачу

- Настройка раскладки отдельно для каждого пространства.
- Изменение порядка папок, их ширины или числа колонок.

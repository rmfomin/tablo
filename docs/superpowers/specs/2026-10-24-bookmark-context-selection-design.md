# Единое hover и выделение закладки

## Цель

Сделать наведение и постоянное выделение закладки прямоугольными областями с одинаковыми границами. Контекстное меню и выделение должны быть независимы: выделение по ПКМ остаётся после закрытия меню.

## Поведение

- Hover подсвечивает прямоугольную область закладки без скруглений.
- ПКМ по невыделенной закладке выделяет только её и открывает контекстное меню.
- ПКМ по закладке из текущего множественного выделения сохраняет весь набор.
- Закрытие меню не снимает выделение.
- Левый щелчок по другой закладке или пустому месту снимает контекстное выделение согласно существующей очистке выбора.
- Цвет постоянного выделения отличается от hover; фокус клавиатуры остаётся отдельным состоянием.

## Подходы

1. Подправить только CSS — не сохраняет выделение после закрытия меню.
2. Использовать существующий `selectedItemIds` и рисовать hover/selection на одной области закладки — сохраняет совместимость с множественным выбором и требует минимум изменений. Выбран этот вариант.

## Ограничения

Не менять поведение групп, открытие ссылок и геометрию строк. Проверить одиночный и множественный контекстный выбор, закрытие меню, hover и сборку.

# Улучшения повседневной работы в Tablo

## Цель

Сделать часто используемые страницы доступнее, упростить переход от результатов поиска к закладкам на панели, обеспечить надёжное обновление фавиконов и добавить настраиваемое напоминание о резервной копии.

## Контекст

Tablo — расширение Chromium, заменяющее новую вкладку панелью закладок. В проекте уже есть история браузера с частотой посещений, импорт и экспорт JSON, поиск по закладкам с расположением результатов по пространствам, папкам и группам, а также кнопка обновления фавиконов. Последняя сейчас повторно выбирает URL из внутреннего кэша и не гарантирует сетевое обновление значка.

## Цели

- Добавить отдельный попап «Часто используемые» с единым списком частых страниц из истории браузера.
- В попапе дать быстрый переход к страницам и возможность добавить в Tablo страницы, которых ещё нет на панели.
- Выбор результата поиска открывает ссылку в браузере. Отдельная кнопка с иконкой `arrow-down-to-dot` переходит к закладке в интерфейсе Tablo, раскрывает её расположение и выделяет её.
- Исправить действие обновления фавиконов: заново получать значки через официальный favicon endpoint Chrome и обновлять закладки текущего пространства.
- Добавить отключаемое напоминание об экспорте резервной копии с настраиваемым интервалом и возможностью отложить напоминание.

## Не входит в объём

- Сохранение открытой вкладки перетаскиванием: такой сценарий уже поддержан.
- Теги, облачная синхронизация, автоматическое создание или загрузка резервных копий.
- Перестройка основной панели или создание отдельной страницы для перечисленных функций.
- Добавление или замена зависимостей.

## Подходы

1. Встроить функции в существующую панель и модели Zustand, используя историю, поиск, экспорт и Chrome Storage, которые уже есть в проекте. Это сохраняет привычный интерфейс и ограничивает изменения текущей архитектурой.
2. Создать отдельную страницу-центр для истории, поиска и резервных копий. Это потребовало бы нового маршрута и более крупной перестройки без добавочной пользы для согласованных сценариев.

Рекомендуемый подход — первый; пользователь его подтвердил.

## Поведение функций

### Попап «Часто используемые»

- Открывается пунктом «Frequently used» в настройках, в том же модальном окне, что и горячие клавиши.
- Использует визиты из истории браузера за последние 7 дней и сортирует страницы по их числу, затем по времени последнего посещения.
- Для каждой страницы показывает число посещений за 7 дней и дату со временем последнего посещения.
- Показывает только страницы, которых ещё нет в Tablo. Страницу можно открыть или добавить в выбранное пространство и папку; после добавления она исчезает из списка.
- Исключает страницы Tablo и адреса, уже сохранённые на панели.
- Не меняет закладки автоматически.

### Переход от поиска к закладке

- Выбор результата закладки открывает URL в браузерной вкладке и закрывает поиск.
- Круглая кнопка «Jump to bookmark» с иконкой `arrow-down-to-dot` встроена в строку результата по образцу кнопки настроек быстрой группы. Она закрывает поиск, выбирает пространство, раскрывает папку и группу при необходимости, прокручивает к закладке и ненадолго выделяет её.
- Нажатие кнопки перехода к закладке не открывает URL в браузере.
- Результаты из истории сохраняют текущее поведение и открывают страницу.

### Обновление фавиконов

- Действие в меню Help проверяет значки закладок текущего пространства: сначала использует favicon соответствующей открытой вкладки, затем официальный endpoint Chrome, сохранённый значок и `/favicon.ico` сайта.
- Для этого добавить permission `favicon` в оба manifest-варианта. Уже запрошенный `tabs` permission не создаёт отдельного предупреждения для него в Chrome.
- Используется favicon, известный Chrome; расширение не пытается принудительно обходить внутренний сетевой кэш Chrome.
- Каждая картинка проходит проверку загрузки с тайм-аутом; одновременно проверяется не более шести закладок. Повторные запросы одного значка объединяются.
- Стандартный значок Chrome не заменяет сохранённую иконку. Результат endpoint сохраняется как изображение в data URL, без привязки к ID установки расширения.
- При ошибке загрузки сохраняется прежний значок. Уведомление показывает прогресс и фактическое число обновлённых, неизменившихся и недоступных значков.
- Изменения сохраняются одним пакетом без новых шагов Undo; устаревший ответ не перезаписывает уже изменённую закладку.
- Изменение favicon открытой вкладки автоматически обновляет соответствующие сохранённые закладки во всех пространствах после проверки загрузки.

### Напоминание о резервной копии

- Пункт меню «Backup reminders» с иконкой колокольчика открывает отдельное модальное окно. Перед пунктом расположен разделитель.
- В окне можно включить или отключить напоминания и ввести положительное целое число дней в числовой input.
- По умолчанию напоминание выключено.
- Период по умолчанию — 30 дней; пользовательское значение сохраняется в Chrome Storage.
- Если полного экспорта ещё не было, первый срок отсчитывается от включения напоминаний.
- Кнопка «Check now» сохраняет настройки и сразу показывает настоящее напоминание, в том числе при выключенном таймере.
- При наступлении срока показывается окно с предложением сделать резервную копию. Подтверждение открывает системный диалог «Сохранить как» для выбора папки и JSON-файла.
- После успешного сохранения из напоминания обновляется дата последнего бэкапа. При отмене или ошибке сохранения дата не меняется; можно повторить экспорт или отложить напоминание на один день.
- Для системного диалога используется `chrome.downloads` с `saveAs: true` и permission `downloads` в обоих manifest-вариантах; завершение сохранения отслеживается через `downloads.onChanged` и `downloads.search`.
- Синхронизации и фоновой записи файла нет.

## Ограничения и решения

- Использовать текущий React, Zustand и Chrome Storage без новых зависимостей.
- Настройки напоминания и время последнего успешного полного экспорта хранить в `chrome.storage.local` через существующую схему предпочтений.
- Частые страницы получать из Chrome History при открытии окна; число визитов за неделю считать по `chrome.history.getVisits`, а не по общему `visitCount`. Не добавлять отдельный сбор телеметрии.
- Ручное обновление фавиконов должно избегать записи временных cache-busting параметров в постоянные данные закладок.
- Существующий экспорт отдельного пространства не сбрасывает таймер полного резервного копирования.
- Локальные инструкции запрещают добавлять и запускать тесты без отдельной просьбы пользователя. Реализацию проверять чтением diff и доступными нетестовыми проверками типов/сборки только если пользователь отдельно разрешит такие проверки.

## Открытые решения для реализации

- Favicon API и разрешение `favicon` выбраны как поддерживаемый Chrome механизм; URL значка строится через `chrome.runtime.getURL("/_favicon/")`, чтобы использовать ID текущей сборки.
- Ранжировать рекомендации по числу визитов за последние 7 дней и использовать время последнего визита при равных значениях.

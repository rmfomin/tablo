# Папки на несколько колонок

Пользователь согласовал управляемое распределение содержимого приложением и запуск реализации

## Поведение

- Ширина папки кратна колонкам общей сетки, изменяется зацепом у правого края
- Число колонок и порядок папок сохраняются в storage и JSON
- На узком экране отображаем доступное число колонок, сохраняя выбранную ширину
- Содержимое читается сверху вниз, затем слева направо по колонкам; соседние папки сдвигаются последовательно
- Заголовок папки занимает только первую колонку; следующие колонки начинаются на его уровне
- Свёрнутая папка занимает одну колонку; разворачивание восстанавливает сохранённую ширину
- Группа может продолжаться в следующих колонках с сохранением отступов и небольшим заголовком продолжения
- Группа остаётся единым объектом: переименование, сворачивание, удаление и перемещение за любой заголовок действуют на всю группу
- Заголовок группы не оставляем без первой закладки внизу колонки
- Во время перетаскивания распределение фиксировано, после завершения пересчитывается
- Изменение ширины сохраняется одним действием после отпускания, Escape отменяет его

## Выбранный подход

Распределение приложением выбрано вместо автоматического CSS-потока: явные части группы позволяют управлять заголовками и целями перетаскивания

## Данные и границы компонентов

- `FolderV3.columnSpan?: number`: положительное целое, отсутствие означает одну колонку
- Порядок папок и элементов остаётся в существующих `position`; пиксельные координаты и части групп не сериализуются
- Root папки: `data-role=folder`, `data-folder-id`, `data-column-span` с эффективным числом колонок
- Каждая колонка: `data-role=folder-items`, `data-folder-id`, `data-column-index`, `data-insert-before-id` для вставки в конце колонки перед следующим элементом общей последовательности
- Часть группы: существующие folder-group/group-header/group-items с одинаковым `data-group-id`; `data-group-fragment` различает части
- Group-items части содержит `data-insert-before-id` следующей закладки той же группы; отсутствие означает конец группы
- Заголовок группы с `data-drop-insert=end` по-прежнему добавляет в конец всей группы
- Глобальное событие `tablo-drag-state` с boolean detail фиксирует/освобождает распределение при перетаскивании закладок и папок

## Проверки

- Ширина переживает экспорт/импорт, старые JSON, сворачивание, изменение окна и undo
- Закладки не дублируются и не теряются, порядок сохраняется через разрывы групп
- Перетаскивание в начало/конец каждой колонки, между частями группы, наружу, в пустую папку и из боковой панели
- Перемещение целой группы из любой её части не дублирует группу и переносит все закладки
- Выделение и клавиатура работают с новыми колонками
- Билд после каждой итерации; целевые проверки перетаскивания и раскладки входят в запрос пользователя

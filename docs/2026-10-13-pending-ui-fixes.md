# Отложенные исправления интерфейса

Дата фиксации: 13 октября 2026 года

Статус: изменения по всем семи пунктам внесены 24 октября 2026 года по команде пользователя. Сборки проходят; проверка поведения в браузере ещё не выполнена.

## Порядок выполнения после запуска

- Выполнять задачи поочерёдно; при необходимости можно использовать агентов
- После каждой итерации самостоятельно выполнять билд и проверять его результат

## 1. Перемещение первого элемента группы на первую позицию папки

- Сценарий: в папке сверху находится группа
- Проблема: первый элемент этой группы нельзя перетащить в ту же папку на первую позицию
- Другие вкладки из других мест перемещаются без этой проблемы
- Ожидается: первый элемент группы можно переместить на первую позицию папки

## 2. Перемещение в новую пустую папку

- Проблема: в только что созданную папку нельзя перетащить закладки или группу
- Текущий обход: создать внутри папки новую вкладку, после чего перетаскивание работает
- Ожидается: пустая папка принимает закладки и группы без предварительного создания вкладки

## 3. Выделение текста без закрытия меню

- Проблема: при выделении имени закладки в меню редактирования выход мыши за пределы инпута закрывает инпут или меню и прерывает выделение
- Ожидается: если выделение началось внутри инпута, движение мыши за пределами инпута или меню продолжает выделение и не закрывает редактор
- Такое же поведение требуется для текстовых инпутов в настройках быстрой группы

## 4. Преобразование группы в папку

- Добавить в контекстное меню группы пункт с кратким названием; реализован как «To folder» в соответствии с языком интерфейса
- Создать новую папку с именем исходной группы
- Перенести все вкладки группы на верхний уровень новой папки, без вложенной группы

## 5. Расположение кнопки Add folder

- В верхней области быстрых групп перенести кнопку Add folder перед кнопкой добавления группы
- Идентификатор из сообщения пользователя: `_addGroupButton_74klg_62`

## 6. Перетаскивание URL в меню быстрой группы

- Для перетаскивания URL через кнопку зацепа использовать визуальное поведение закладок: полупрозрачное превью в предполагаемом месте вставки
- У кнопки зацепа убрать эффект hover
- Иконку зацепа расположить по вертикальному центру инпута; сейчас она прижата к низу

## 7. Открытие группы быстрых вкладок вместо текущей вкладки

- При открытии группы быстрых вкладок всегда заменять текущую вкладку независимо от настройки открытия вкладок

# Прототип холста AFFiNE в Tablo

Эксперимент для проверки автономного редактора BlockSuite внутри Tablo с несколькими локальными холстами. Это интеграция редактора, а не полное приложение AFFiNE

## Запуск

```sh
npx vite --config vite.demo.config.ts --host 127.0.0.1 --port 5173
```

Открыть <http://127.0.0.1:5173/tablo/demo.html> и нажать кнопку «Открыть холст» рядом с настройками в боковой панели. Отдельная страница редактора: <http://127.0.0.1:5173/tablo/canvas-prototype.html>

## Возможности

- По умолчанию один пустой холст «Холст 1»; существующий холст сохраняется при обновлении
- Список холстов в меню, активный выделен; кнопка «Добавить холст» создаёт новый пустой холст и открывает его
- Редактирование текста, фигуры, карточки, связи, перо, масштабирование и отмена действий средствами BlockSuite
- Загрузка PNG, JPEG, WebP или GIF до 10 МБ через иконку картинки на нижней панели
- Опция «Оптимизировать изображения при вставке» включена по умолчанию: статичные PNG/JPEG/WebP преобразуются локально в WebP с качеством 85% и ограничением 1920 px по длинной стороне. Если файл не уменьшился или конвертация не удалась, сохраняется оригинал; GIF/APNG/анимированный WebP не перекодируются
- Автосохранение документа и изображений в IndexedDB
- Экспорт отдельного JSON для текущего холста или всех холстов, до 64 МБ при импорте
- При экспорте можно выбрать «С картинками» или «Без картинок». Во втором варианте бинарные данные не включаются; при импорте на месте изображений создаются заглушки, размеры, идентификаторы и подписи сохраняются. Исходный холст при экспорте не меняется
- Возврат к закладкам с ожиданием завершения сохранения
- Светлая, тёмная и системная тема из настроек Tablo, включая смену темы в уже открытом холсте
- В настройках можно выбрать компактную панель с иконками или подробную штатную панель BlockSuite с меню фигур, цветов, толщины линий и пресетами фреймов. По умолчанию — компактная; переключение не перезагружает редактор
- Прозрачная верхняя панель с возвратом, названием холста и меню; статусы, импорт, экспорт, настройки и ссылка BlockSuite собраны в меню
- Переименование двойным щелчком по названию рядом с кнопкой «Назад»; с клавиатуры — Enter или F2. Название сохраняется в документе и переносится через JSON
- Общие «Настройки холстов» для всего набора: панель инструментов, фон, сетка, направляющие, открытие и оптимизация изображений
- Настройки фона: точки, линии или без сетки; цвета следуют теме Tablo
- Привязка при перемещении объектов к сетке с шагом 20 px и отдельный переключатель направляющих. При включении обоих режимов выравнивание по соседним объектам имеет приоритет
- Открытие холста: восстановить позицию и масштаб или показать всю схему
- Шрифты Inter и Kalam входят в билд и не требуют сети. Выбор начертания («Regular») скрыт в контекстной панели по запросу пользователя; существующее форматирование документа сохраняется

## Устройство

- Редактор загружается в локальном iframe только после открытия режима
- Режим `edgeless` задан явно через публичный `DocModeExtension`. Сам по себе `EdgelessEditor` не настраивает `DocModeProvider`: без этого абзацы делали весь корневой блок редактируемым, ломая ввод и сохранение названий фреймов и текста фигур
- Шрифты холста зарегистрированы через публичный `FontConfigExtension` под именами `blocksuite:surface:*`. Обычный CSS-шрифт интерфейса не заполняет список начертаний BlockSuite; каждому весу Inter соответствует отдельный FontFace с общим локальным variable-файлом
- Отдельная HTML-страница включена в обе конфигурации Vite
- React и стили основного Tablo не подключаются к редактору
- В основе — опубликованный BlockSuite 0.19.5, а не текущий интерфейс AFFiNE
- Документы сохраняются через `IndexedDBDocSource`, изображения — через `IndexedDBBlobSource`
- Оптимизация подключена перед вычислением хеша в `blobSync.set(Blob)`, поэтому работает для кнопки, вставки из буфера и перетаскивания через BlockSuite. Импорт по готовым ключам и уже сохранённые изображения не перекодируются
- JSON содержит состояние Yjs в Base64 и бинарные изображения в Base64. Это формат прототипа, не стандартный экспорт AFFiNE
- Экспорт включает только используемые `sourceId`, без накопившихся неиспользуемых файлов. Необязательное поле `imagesIncluded=false` обозначает экспорт без картинок; старые JSON без поля остаются совместимыми
- JSON версии 2 содержит несколько документов и `activeDocId`; импорт версии 1 с одним документом поддерживается. Экспорт текущего холста собирает новый корневой документ без метаданных других холстов; картинки между выбранными холстами не дублируются
- Импорт сначала проверяется в памяти через `NoopDocSource` и `MemoryBlobSource`, без создания временных баз IndexedDB, затем добавляет документы как независимые копии с новыми ID в существующий набор. Текущие холсты и общие настройки остаются на месте; импортируемые настройки используются при самостоятельном восстановлении файла в новое хранилище
- Импорт с отсутствующими изображениями отклоняется. Все совпадающие ключи картинок сравниваются по содержимому и MIME до первой записи: повреждённый файл не может заменить существующее изображение при импорте. Совпадающие картинки повторно не записываются
- При ошибке открытия импортированного набора удаляются только созданные этой операцией документы; холсты, добавленные параллельно, сохраняются
- `backup.ts` отвечает за формат JSON и проверку файла, `storage.ts` — за сессии, `canvas-controller.ts` — за переключение и откат операций, `editor-runtime.ts` — за монтирование и освобождение редактора. Незавершённая инициализация отменяется при закрытии; адаптация внутреннего DOM библиотеки изолирована в `blocksuite-compat.ts`
- Статус сохранения обновляется после записи. Ошибки показываются на экране
- Тема передаётся из Tablo в iframe через сообщения с проверкой источника и origin; системная тема отслеживается через `prefers-color-scheme`
- Штатная панель BlockSuite сохранена в стандартном наборе виджетов; в компактном режиме она скрыта стилями оболочки. Обе панели используют один `GfxControllerIdentifier`, поэтому переключение сохраняет инструмент, документ, камеру и историю отмены. Код npm-пакетов не изменяется
- Общие параметры хранятся в Y.Map корневого документа коллекции. Старые параметры одиночного холста автоматически переносятся из его Y.Map; по умолчанию — компактная панель, точки, привязка выключена, направляющие включены, восстановление вида, оптимизация изображений включена
- Каждый холст — отдельный документ BlockSuite со своей историей отмены. Последний активный документ запоминается локально вместе с активной коллекцией
- Привязка добавлена через публичное расширение `OverlayIdentifier` с наследником `EdgelessSnapManager`. Фон оформляется стилями оболочки, камера управляется через публичный `gfx.viewport`
- Последняя позиция камеры хранится локально для пары коллекция/документ и не переносится через JSON; настройка способа открытия переносится
- Экспорт документа работает из памяти и не требует успешной записи документа в IndexedDB

## Ограничения

- Удаление и сортировка холстов пока не добавлены
- Холст не включён в общий бэкап закладок
- Браузерное демо и установленное расширение используют разные хранилища; для переноса нужен экспорт и импорт
- PNG/SVG-экспорт не включён: встроенный PNG-экспорт не дал подтверждённого результата в этом прототипе
- Полная работа без сети и запуск в установленном Chrome требуют отдельной проверки: управление пользовательским Chrome недоступно
- Часть инструментов BlockSuite рассчитана на сервисы AFFiNE и пока не адаптирована
- Не настроены лимиты общего хранилища и восстановление при исчерпании квоты. Новые временные импорты не записываются на диск; базы старых версий автоматически не удаляются. Очистка неиспользуемых картинок требует отдельного решения с учётом истории отмены и других открытых вкладок
- У пакета иконок зафиксирована версия 2.1.75: новые версии удалили экспорт, используемый BlockSuite 0.19.5. npm предупреждает о диапазоне Node, рассчитанном на более старые версии
- npm сообщает об уязвимостях в дереве зависимостей; их разбор и обновление нужны перед выпуском, прототип не готов к публикации

## Проверка

- Проверка типов основного приложения и прототипа: `npm run typecheck`
- В браузере проверены открытие из боковой панели, изменение текста, выход и восстановление изменений, загрузка и восстановление изображения, рисование пером
- Скачанный JSON содержит один документ и JPEG; импорт в новое локальное хранилище восстанавливает карточки и изображение
- После сообщения об ошибке в расширении выполнена сборка `npm run build` с отдельного разрешения пользователя
- В готовом билде воспроизведена ошибка `Input is not a service identifier`: минификатор убирал имена классов, используемые контейнером сервисов BlockSuite. Для обеих конфигураций Vite включён `output.keepNames`
- В оба манифеста добавлена политика `script-src 'self' 'wasm-unsafe-eval'; object-src 'self';`, разрешающая WebAssembly для подсветки кода. Загрузка скриптов с внешних серверов и выполнение JavaScript через `eval` не разрешены
- Для проверки используется просмотр готового `dist` с HTTP-заголовком CSP, взятым из манифеста. Это проверка production-ресурсов и ограничений CSP, а не запуск в установленном расширении
- Исправленный production-билд отрисовал три карточки и панель инструментов; в консоли при запуске не было ошибок регистрации сервисов и WebAssembly
- Дополнительно исправлен запуск фонового скрипта: `keepNames` вынес общий helper в ESM-чанк, а манифест объявлял worker классическим скриптом. В обоих манифестах установлен `background.type=module`
- До исправления собранный worker не проходил синтаксический разбор с ошибкой `Cannot use import statement outside a module`. После исправления в изолированной среде выполнен именно собранный ESM-код: проверены регистрация обработчиков, ответ `get-last-active-tabs` и открытие `newtab.html`
- Основная страница из `dist` проверена в браузере с изолированной эмуляцией Chrome API: отрисовались закладки, переход в холст работает, консоль без ошибок. Это не проверка пользовательского профиля Chrome
- Проверены светлая и тёмная темы, смена темы из второй вкладки без перезагрузки холста, создание эллипса, толщина пера, отмена и повтор действий в компактной панели
- Проверены меню, запрет пустого названия, переименование с восстановлением после перезагрузки, экспорт и импорт названия вместе с документом
- Проверены три вида фона, движение карточки с координатами, кратными 20 px, выравнивание по соседней карточке при выключенной сетке, точное восстановление позиции и масштаба после перезагрузки, режим показа всей схемы и перенос параметров через JSON
- Воспроизведён сбой переименования фрейма: Enter изменял DOM холста, а название не попадало в документ. После настройки режима проверены подтверждение через Enter и клик снаружи, восстановление названия после перезагрузки и неизменное количество фреймов
- Дополнительно проверено восстановление текста новой карточки, отдельного текста, текста фигуры и загруженной картинки после перезагрузки
- В изолированной DOM-проверке воспроизведён пустой список без конфигурации шрифтов; с конфигурацией настоящий компонент BlockSuite показывает Light, Regular и Semibold для Inter и Kalam, все варианты доступны и передают выбранный вес. Проверены наличие локальных TTF и удаление регистраций при отключении редактора. Визуальная проверка этой правки не выполнялась: управление браузером отключено в Work
- Для повторной проверки в Chrome нужно перезагрузить расширение из обновлённой папки `dist` на странице `chrome://extensions`, затем открыть новую вкладку Tablo
- Для оптимизации и экспорта добавлены целевые проверки: размер/качество/откат конвертации с подменёнными Canvas API, сохранение анимации, настройка оптимизации в JSON, старый формат импорта, исключение неиспользуемых файлов, отсутствие исходных байтов в экспорте без картинок и восстановление заглушек без изменения оригинала. Реальное кодирование WebP и внешний вид новых окон в Chrome не проверены: управление браузером отключено в Work
- Для нескольких холстов проверены общие настройки, миграция JSON версии 1, создание и переименование, восстановление набора и активного холста, изоляция содержимого, экспорт текущего без чужих метаданных и картинок, экспорт всех в обоих режимах картинок, импорт независимых копий и отказ без изменения исходного набора при повреждённом файле или ошибке чтения картинки
- Для режима панели проверены компактный вариант по умолчанию, переключение видимости без пересоздания кнопок и редактора, применение настройки из другого холста и сохранение подробного режима через экспорт текущего или всех холстов. Внешний вид штатных меню в Chrome не проверен: управление браузером отключено в Work
- При рефакторинге добавлены проверки отклонения повреждённых файлов без изменения активного набора, импорта в памяти, восстановления скопированных изображений после повторного открытия, конфликтов ключей картинок, отката неудачного монтирования без удаления параллельно созданных документов, удаления подписок и отмены ожидающего редактора при закрытии
- `extensionBuild.test.ts` выполняет собранный ESM worker в изолированном контексте Node с подменой Chrome API: проверяет обработчики, последние вкладки и открытие Tablo. Дополнительно проверяет наличие локальных стартовых ресурсов, module-манифест и политику WASM. Это автоматическая проверка артефакта сборки, а не установленного расширения
